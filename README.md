# French Course

**Le voyage de Carolina · Français 0→10** is a single-file French learning site. Open `index.html` in a browser, or use the GitHub Pages link below.

The course follows a journey across Quebec, from Lévis to the Îles-de-la-Madeleine, with lessons, postcards, city badges, and a certificate.

Live site: https://nestormiron.github.io/French-Course/
