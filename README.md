# French Course

**Le voyage de Carolina · Français 0→21** is a single-file French learning site. Open `index.html` in a browser, or use the GitHub Pages link below.

The course follows a journey across Quebec, from Lévis to Vieux-Québec, with lessons, postcards, city badges, live speaking challenges, and a certificate. Progress stays on the phone and also syncs to a private read-only page (`nestor.html`), which opens only with its private link.

Live site: https://nestormiron.github.io/French-Course/
